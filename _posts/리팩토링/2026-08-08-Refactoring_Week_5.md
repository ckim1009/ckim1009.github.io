# Security Monitoring
## Definition of Security Monitoring

Security monitoring is the continuous process of monitoring an organization's networks, systems, applications, and security events to detect, analyze, and respond to potential security threats and incidents.

## Three Principles of Security Monitoring

1. Continuous Availability: Security monitoring operates continuously 24/7 through day and night shifts, ensuring that security threats can be detected and responded to without interruption.

2. Expertise: Security monitoring requires specialized knowledge and expertise to accurately detect, analyze, and respond to security threats.

3. Information Sharing: Security-related information and threat intelligence should be shared among relevant teams and organizations to improve security awareness and response capabilities.

## Security Monitoring Operations

1. Prevention: Identify and address vulnerabilities and strengthen security controls to prevent security incidents.

2. Detection: Continuously monitor security events and detect abnormal activities and potential security threats.

3. Response: Analyze detected threats and take appropriate actions to contain the threat and minimize potential damage. Collaborate with relevant teams to coordinate and perform incident response activities.

4. Reporting: Document and report security incidents, analysis results, and response activities to relevant personnel and organizations.

5. Sharing and Improvement: Share incident information and lessons learned, and improve security policies, detection rules, and response procedures to prevent similar incidents from recurring.

## Types of Security Monitoring

### 1. On-site Security Monitoring

Security monitoring personnel from a security service provider are stationed at the customer's premises and directly perform monitoring and incident response activities.

### 2. Remote Security Monitoring

A security service provider remotely monitors and analyzes security events collected from the customer's systems and security devices.

### 3. In-house Security Monitoring

An organization operates its own security monitoring center and directly manages security monitoring, analysis, and incident response activities.

## Web Services and Tools Used for Security Monitoring

### 1. Whois (KISA)

A service provided by the Korea Internet & Security Agency (KISA) for looking up domain and IP address registration information.

### 2. VirusTotal

An online security analysis service that analyzes suspicious files, URLs, IP addresses, and domains using multiple antivirus engines and threat intelligence sources.
